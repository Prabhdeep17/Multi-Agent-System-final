1. The Global Architecture Flow (V2: Pure Chatbot)

The system now operates as a sleek, edge-to-edge Chat UI. It strictly separates asynchronous data ingestion (sidebar) from the dynamic multi-agent reasoning graph (main window).

[DATA INGESTION PHASE - Sidebar] User Uploads PDF => app.py ↓ pdf_processor.py (Splits PDF into 1000-char chunks via RecursiveCharacterTextSplitter) ↓ vector_store_manager.py (Runs local all-MiniLM-L6-v2 to convert text -> math vectors) ↓ ChromaDB (Saves vectors and exact page metadata locally) [MULTI-AGENT REASONING PHASE - Main UI] User Types in Chat => app.py (handle_user_query triggers st.chat_input) ↓ planner.py (AgentOrchestrator) ↓ [IntentDetector queries Gemini-3-Flash-Preview] ↓ Is it a QUERY? => YES => Routes to rag_agent.py Is it a SUMMARY? => YES => Routes to summarization_agent.py ↓ Agent Queries ChromaDB for precise Evidence ↓ Agent Builds SystemMessage + HumanMessage Strict Prompt ↓ Gemini Returns List/JSON Output => Safely Parsed to Python String ↓ Streamlit Appends Answer to Chat History

2. Complete Technical Code Breakdown

.env & config.py

The Foundation. The application dynamically loads API keys and models using python-dotenv. The override=True flag forces the app to prioritize the .env file over conflicting system environment variables.

# config.py - Ensuring clean environment loading
import os
from dotenv import load_dotenv

load_dotenv(override=True)

class Config:
    LLM_PROVIDER = os.getenv("LLM_PROVIDER", "google") # Actively using Gemini
    LLM_MODEL = os.getenv("LLM_MODEL", "gemini-3-flash-preview")
    CHUNK_SIZE = int(os.getenv("CHUNK_SIZE", "1000"))
app.py

The Pure Chat Canvas. The UI was deliberately gutted of complex split-screens and feature menus to achieve a 100% pure chatbot interface. Streamlit's reactive rendering is managed via st.session_state to ensure the chat history survives page reloads without resetting the database.

# app.py - The streamlined chatbot logic
if not st.session_state.processing_complete:
    with st.chat_message("assistant"):
        st.markdown("👋 Hello! Please upload your PDF documents in the sidebar.")
else:
    display_chat_history() # Repaints previous memory on reload
    
    # Full-width chat input locked to the bottom of the screen

planner.py (AgentOrchestrator)

The Traffic Cop. Unlike traditional basic chatbots, this uses an IntentDetector. Before acting, it evaluates exactly what the user is asking and routes them to the correct expert AI. This prevents hallucination when doing complex tasks.

# Inside planner.py - The Gemini Payload Fix
messages = [
    SystemMessage(content="Determine if the user wants a SUMMARY, a QUERY, or a COMPARISON."),
    HumanMessage(content=query)
]
response = self.llm.invoke(messages)

# CRITICAL FIX: The Google GenAI library occasionally returns a List of dictionary objects

content = response.content
if isinstance(content, list):
    content = "".join(item.get("text") for item in content if item.get("type") == "text")
intent_str = content.strip().upper()
agents/rag_agent.py & summarization_agent.py

The Specialized Experts. After routing, these agents execute complex logic using the LLM utilities.

  • RAG Agent (rag_agent.py): Implements Retrieval-Augmented Generation. It searches ChromaDB for exact matching text chunks. It then forces Gemini to cite the exact source [1], ensuring absolutely no hallucinations.
  • Summarization Agent (summarization_agent.py): Implements an enterprise Map-Reduce logic. An AI cannot memorize a 500-page book at once. This agent retrieves all chunks, loops through them to summarize them individually (MAP), and then sends those tiny summaries back to the LLM to merge them into one giant response (REDUCE).
vector_store_manager.py

The Semantic Engine. We use HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2"). It runs completely locally on your CPU—no data is sent to external clouds for indexing, saving thousands of API requests.

When the user asks "How much revenue is expected?", the vector store converts the query into math vectors, runs a Cosine Similarity algorithm against the chunks in ChromaDB, and fetches the top 5 most semantically relevant paragraphs instantly.
